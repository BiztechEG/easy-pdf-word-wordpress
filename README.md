# Easy PDF & Word for WordPress

A WordPress plugin built on [biztecheg/easy-pdf-word](https://github.com/BiztechEG/easy-pdf-word): PDF and Word (.docx) documents with first-class Arabic support, and invoices, tax invoices (ZATCA), Egyptian invoices, credit notes and delivery notes for WooCommerce orders.

Work in progress. Docs: https://easypdf.biztech-eg.com
